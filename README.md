# مستقبل وطن | قطاع الأعمال — نسخة عرض تجريبية (واجهة فقط)

تطبيق جوال عربي بالكامل (RTL) لإدارة لجان **أمانة قطاع الأعمال المركزية**: اللجان، المقترحات ومتابعة حالتها، المشروعات وموقفها المالي، الأنشطة، الاجتماعات والاتصال المرئي، ومتابعة المحافظات.

> ⚠️ **تنبيه مهم:** هذه نسخة **واجهة أمامية تجريبية فقط**. لا يوجد خادم أو قاعدة بيانات أو تسجيل دخول حقيقي.
> - أسماء **قيادة الأمانة وهيئة المكتب ومسؤولي اللجان حقيقية** (من قرار تشكيل هيئة المكتب ومخطط تقسيم الأمانة إلى ١٠ لجان)، أما أرقام هواتفهم وبريدهم الإلكتروني فهي **افتراضية**.
> - **توزيع المحافظات على الأمناء المساعدين وأسماء أمناء المحافظات بيانات تجريبية** — القرار لا يحددها.
> - باقي البيانات (المقترحات، المشروعات والميزانيات، الاجتماعات، الأعضاء العاديون…) **وهمية** ومحفوظة **في الذاكرة فقط** وتعود لحالتها الأولية عند إعادة التحميل.
> - الصلاحيات **محاكاة على الواجهة** وليست حماية أمنية.
> - **الاتصال المرئي محاكاة**: لا يتم نقل أي صوت أو صورة، والواجهة تقول ذلك صراحة.
> - المرفقات تبقى كبيانات وصفية خلال الجلسة ولا تُرفع لأي جهة. الشعار المعروض مؤقت.

## التقنيات

| المجال | التقنية |
|---|---|
| الإطار | Expo SDK 58 + React Native 0.88 (New Architecture) |
| اللغة | TypeScript (strict) |
| التنقل | Expo Router (`app/`) |
| الحالة | Zustand 5 — في الذاكرة فقط، مقسمة إلى شرائح (slices) |
| الأيقونات / الخط | lucide-react-native / Noto Sans Arabic + Poppins |
| النماذج | React Hook Form + Zod |
| أخرى | expo-linear-gradient, expo-document-picker, react-native-svg (للرسوم), expo-haptics, expo-localization |

جميع الحزم مضمّنة في **Expo Go**، فلا يلزم بناء تطوير للتجربة.

## التشغيل

```bash
npm install
npx expo start          # ثم امسح رمز QR بتطبيق Expo Go
npx expo start --web    # تجربة سريعة في المتصفح
```

للتحقق: `npx tsc --noEmit` و `npx expo lint`.

التطبيق يُعرض من اليمين لليسار بغض النظر عن لغة الجهاز (Yoga `direction: 'rtl'` على الجوال، و`<html dir="rtl">` على الويب).

## النشر على Vercel (نسخة الويب)

الإعدادات جاهزة في `vercel.json`: أمر البناء `expo export -p web`، ومجلد الناتج `dist`، وإعادة توجيه كل المسارات إلى `index.html` حتى تعمل الروابط المباشرة (التطبيق بوضع `web.output: "single"`).

- **من GitHub:** في Vercel اختر **Add New → Project** واستورد هذا المستودع، واترك الإعدادات كما هي (يقرأها Vercel من `vercel.json`)، ثم **Deploy**. كل دفع (push) لاحق يُنشر تلقائياً.
- **من سطر الأوامر:** `npx vercel` للمعاينة، و`npx vercel --prod` للنشر النهائي.
- للتجربة محلياً قبل النشر: `npx expo export -p web` ثم افتح محتوى `dist`.

البيانات في الذاكرة فقط، لذا يبدأ كل زائر من البيانات التجريبية الأولية ولا تُحفظ التغييرات بين الزيارات.

## الأدوار والصلاحيات

لكل شخص **دور واحد**، و«مسؤول اللجنة» **صلاحية تُضاف** لأي شخص (قائمة اللجان التي هو مسؤول عنها) وليست دوراً مستقلاً. كل الصلاحيات معرّفة في مكان واحد: `src/utils/permissions.ts` (مصفوفة `ROLE_CAPABILITIES` + فحوص مرتبطة باللجنة أو المحافظة) لتسهيل تطبيقها لاحقاً على الخادم.

| الدور | أبرز الصلاحيات |
|---|---|
| **الأمين** (أمين قطاع الأعمال) | يرى كل اللجان والمقترحات والمشروعات والاجتماعات، **الملخص المالي**، يبت في المقترحات (مراجعة / موافقة / رفض)، ينشئ الاجتماعات ويبدأ الاتصال المرئي، لوحة متابعة شاملة |
| **الأمين المساعد** | مثل عضو الهيئة + **متابعة المحافظات المسندة إليه** (أمناء المحافظات، أنشطتها، مقترحاتها ومشروعاتها) |
| **عضو الهيئة** | يطّلع على اللجان والمقترحات والأنشطة والتقارير، ينظم الاجتماعات العامة ويشارك في الاتصال المرئي |
| **مسؤول اللجنة** (صلاحية) | يقدّم مقترحات لجنته ويتابع حالتها، يدير مشروعات وأنشطة وتقارير لجنته، ينشئ اجتماعات لجنته، ويرى منجزات اللجان الأخرى |
| عضو (حسابات تجريبية) | يطّلع على لجنته وأنشطتها ومقترحاتها واجتماعاته، ويرسل الملاحظات والطلبات |
| مدير النظام (حساب تجريبي) | كل ما سبق + إدارة الأعضاء واللجان والمحافظات والإعدادات |

**البيانات المالية** (الميزانيات والمصروفات) لا تظهر إلا للأمين ومدير النظام.

## التنقل

خمسة تبويبات للجميع، ومحتواها يتغير حسب الصلاحيات:

1. **الرئيسية** — لوحة مختلفة لكل دور (الأمين / الأمين المساعد / عضو الهيئة / مسؤول اللجنة / عضو).
2. **اللجان** — دليل اللجان العشر؛ صفحة كل لجنة: نظرة عامة، المقترحات، المشروعات، الأنشطة، الأعضاء، التقارير.
3. **المقترحات** — تصفح المقترحات حسب الصلاحية، وتقديم مقترح جديد بنموذج قصير.
4. **الاجتماعات** — القادمة والسابقة، الاجتماعات الجارية أولاً، والانضمام للاتصال المرئي.
5. **المزيد** — الملف الشخصي، الملخص المالي (للأمين)، المحافظات (للأمناء المساعدين والأمين)، التقارير، المشروعات، الأنشطة، الإعلانات، الإشعارات، الملاحظات، الطلبات الإدارية، أدوات مدير النظام.

## الحسابات التجريبية

كلمة المرور لجميع الحسابات: **`123456`** — أو اضغط على أي حساب في شاشة الدخول. لكل شخص حقيقي حساب (٢٧ حساباً)، أبرزها:

| الدور | الاسم | الهاتف |
|---|---|---|
| الأمين | أحمد خالد حسين عوني العتال | 01000000001 |
| الأمين المساعد + مسؤول لجنة الاستثمار | محمد فكري عيسى عيسى | 01000000009 |
| الأمين المساعد + مسؤول لجنة التطوير العقاري | النائب أحمد حسين أحمد محمد حسين الشناوي | 01000000002 |
| عضو الهيئة + مسؤول لجنة التكنولوجيا | أحمد جمال عبدالحافظ الزيات | 01000000010 |
| عضو الهيئة (بدون لجنة في المخطط) | كاميليا محمد صابر أحمد السعدني | 01000000012 |
| مسؤول لجنة الاستثمار | محمد عادل عياد | 01000000024 |
| مدير النظام (تجريبي) | شريف عبد العزيز | 01000000025 |
| عضو تجريبي | أحمد محمد | 01000000026 |

الأرقام 01000000002–09 للأمناء المساعدين و01000000010–23 لأعضاء الهيئة بترتيب القرار. القائمة الكاملة في `src/data/mockMembers.ts`. زر **«تبديل الحساب التجريبي»** في «المزيد» يبدّل الحساب فوراً مع الإبقاء على التغييرات.

## سيناريوهات التجربة

### تقديم مقترح والبت فيه
1. ادخل كـ **محمد عادل عياد** ← الرئيسية ← **تقديم مقترح** ← اكتب العنوان والوصف والهدف ← **تقديم المقترح**.
2. بدّل إلى **أحمد خالد حسين عوني العتال** (الأمين) ← تبويب **المقترحات** (عليه عدد المقترحات المعلقة) ← افتح المقترح ← **بدء المراجعة** ثم **الموافقة** مع ملاحظة.
3. بدّل إلى عياد: يصله إشعار، ويمكنه **بدء التنفيذ** ثم **تم الإنجاز**.

### الاتصال المرئي
1. ادخل كـ **محمد فكري عيسى عيسى** ← تبويب **الاجتماعات**: «اجتماع تنسيق المحافظات» جارٍ الآن ← **انضمام إلى الاجتماع** (واجهة تجريبية: كتم، كاميرا، المشاركون، مغادرة).
2. لإنشاء اجتماع مرئي: **اجتماع جديد** ← «اجتماع عام» أو لجنة ← نوع «مرئي» ← المشاركون ← إنشاء. يبدأه المنظم من صفحته بزر **بدء الاجتماع**، فيُشعَر المشاركون ويمكنهم الانضمام.

### الملخص المالي
الأمين ← **المزيد** ← **الملخص المالي للمشروعات**: الميزانية والمصروف والمتبقي ونسبة الصرف، المصروف حسب اللجنة، والمشروعات التي تجاوزت ميزانيتها. من صفحة أي مشروع يمكنه **تحديد/تعديل الميزانية**.

### المحافظات
الأمين المساعد ← الرئيسية: بطاقة «المحافظات» (اختر المحافظة من القائمة) — أو «المزيد» ← **محافظاتي** ← افتح محافظة: المنسق، أمناء وممثلو المحافظة، أنشطتها ومقترحاتها ومشروعاتها. مدير النظام يغيّر المنسق من صفحة المحافظة.

### إعادة تعيين البيانات
«المزيد» ← **إعادة تعيين البيانات**، أو أعد تحميل التطبيق.

## هيكل المشروع

الدليل الكامل (القواعد، من يستورد مِن مَن، وأين يوضع الكود الجديد): [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md).

```text
app/                      # مسارات Expo Router — ملفات رفيعة تعيد تصدير الشاشة فقط
src/
  screens/<Name>Screen/   # مجلد لكل شاشة: .tsx · .styles.ts · .data.ts (النصوص) · index.ts
  features/<domain>/      # services (منطق بلا React) · hooks · context (شريحة المتجر) · components · types.ts
  components/             # common · ui · layout · feedback · forms — واجهات عامة تأخذ البيانات عبر props
  navigation/             # شريط التبويبات وتعريفاته وبوابة الدخول
  context/                # المتجر المركّب (appStore) وحالة الواجهة (التنبيهات والحوارات) والسمة
  theme/                  # نظام التصميم: الألوان والخطوط والمسافات والزوايا والظلال والحركة
  hooks/  types/  utils/  config/  constants/images.ts  data/
```

البيانات: ١٠ لجان حقيقية، ٥٠ شخصاً (٢٤ حقيقياً + مدير النظام + ٢٥ عضواً تجريبياً)، ٢٧ محافظة، ١٧ مقترحاً، ٢٠ مشروعاً بميزانياتها، ٢٣ اجتماعاً (منها ٣ عامة وواحد جارٍ الآن)، ٢٠ نشاطاً.

### الربط بخادم أو مزود اتصال مرئي مستقبلاً
- كل عمليات البيانات تمر عبر إجراءات المتجر (`src/store/slices/*`) وتعيد `Result<T>`؛ يكفي استبدالها باستدعاءات API بنفس التوقيعات.
- الاتصال المرئي يمر عبر الواجهة `VideoProvider` في `src/services/video/`. لربط مزود حقيقي: نفّذ الواجهة باستخدام SDK المزود وصدّره من `services/video/index.ts` (يتطلب غالباً بناء تطوير بدلاً من Expo Go).

## قيود معروفة
- لا تخزين دائم ولا إشعارات دفع (Push) — الإشعارات داخل التطبيق فقط.
- الصلاحيات محاكاة على الواجهة فقط.
- الاتصال المرئي محاكاة بدون صوت أو صورة.
- توزيع المحافظات وأسماء أمنائها بيانات تجريبية؛ كاميليا محمد صابر أحمد السعدني غير مدرجة تحت أي لجنة في المخطط.
- أُزيلت خصائص الحوافز والمكافآت والمهام بالكامل.
